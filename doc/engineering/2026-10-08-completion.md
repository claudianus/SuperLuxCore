# 2026-10-08 미완료 수정 마감과 저장소 정리

## 변경

높이 텍스처의 Add/Subtract 범프는 단위 법선을 직접 더하거나 빼지 않고,
각 법선에서 높이 기울기를 복원하여 합성한다. 큰 기울기에서도 원래 높이장의
미분과 일치한다. CPU와 OpenCL/Metal에 같은 계산을 적용했다.

GPU Scale 범프의 두 번째 입력 예외 분기가 첫 번째 입력의 기울기를 지우던
오류와 Mix 범프가 혼합 계수 대신 두 번째 입력의 법선을 사용하던 오류를 수정했다.
범프 필터 간격은 등방성 광선 풋프린트와 위치 정밀도 하한으로 계산한다.
이 간격은 완전한 화면 공간 광선 미분 전달을 대신하는 근사다.

애드온에서는 Cycles 픽셀 필터의 종류별 지지 구간과 Gaussian 감쇠 계수를
가져오도록 마무리했다. 검증 기록은 애드온의
`doc/engineering/cycles-pixel-filter.md`에 있다.

## 현재 소스 검증

Release의 `pysuperluxcore`와 `luxcoreconsole`을 빌드했다. macOS GPU 접근이
제한된 실행 환경에서는 OpenCL 장치 열거가 실패하므로 GPU 테스트는 장치 접근을
허용한 실행 환경에서 수행했다. 격리 Blender 프로필에 바이너리와 wheel을
동기화했고 Blender Python에서 2.11.12 임포트를 확인했다.

| 검증 | 결과 |
|---|---|
| `dev-tools/bump-composition-regression.py` | CPU·Metal Add/Subtract/Mix 6조건 통과, 해석적 법선과 최대 오차 0.000001 미만 |
| `dev-tools/bump-differential-regression.py` | 일반·비균일·음수 스케일 CPU·Metal 6조건 통과 |

## 720p 시각 확인과 남은 차이

Blender 5.2.1 LTS, 1280×720, 128샘플, 디노이즈·클램프 비활성화로
065 씬의 Desert_Sand 재질을 평면에 적용해 Cycles와 Metal에서 렌더했다.
선형 EXR과 AgX PNG를 보존하고 두 이미지를 직접 확인했다.

근거리 영역의 선형 평균 밝기는 Cycles 0.1976, 엔진 0.2542로 비율 1.286이다.
중거리 영역은 0.2338 대 0.2742로 비율 1.173이다. 표면 무늬와 대비 차이도
남아 있다. 범프 합성의 수학적 정확성 검증과 실재질의 Cycles 호환성은 서로
다른 판정이며, 이 작업으로 사막 재질 호환 완료를 선언하지 않는다.
화면 공간 미분·풋프린트와 복합 범프 셰이딩의 추가 검증이 필요하다.

작업공간 산출물은 `test-scenes/validation-2026-10-08/`에 있다.
테스트 로그는 같은 폴더의 `logs/`에 보존했다. 다른 플랫폼의 실행 검증과
전체 건틀릿 성능 재측정은 이번 작업의 검증 범위에 포함하지 않았다.

## 저장소 정리

정리 전 엔진 main은 원격보다 21커밋, 애드온 main은 15커밋 앞서 있었다.
두 저장소의 최근 기능 커밋과 이번 마감 변경을 main에 반영하여 푸시한다.
의존성 저장소는 원격의 6210a2d 커밋까지 fast-forward했다.

세 저장소에 추가 로컬 브랜치나 연결된 추가 워크트리는 없었다.
오래된 엔진 stash 4개는 전체 부모 이력을 포함한 Git bundle로 보존하고
`git bundle verify` 통과 후 제거했다. 미추적 실험 산출물 5개도 해시를
비교한 사본을 만든 뒤 저장소 루트에서 정리했다. 복구 사본과 안내는
작업공간의 `cleanup-backups/2026-10-08/`에 있다.

버전은 2.11.12를 유지하며 새 릴리스 태그는 생성하지 않는다.
