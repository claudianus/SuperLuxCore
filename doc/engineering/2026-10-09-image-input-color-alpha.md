# 기존 이미지의 입력 색 공간·알파·축소 캐시

Blender 이미지의 sRGB를 감마 2.2로 근사하면 암부가 바뀌며 ACEScg·ACES2065-1·Rec.2020 입력도 해석되지 않는다. 확장이 Blender의 실제 OCIO 설정 파일과 이미지 색 공간 이름을 전달하고, 엔진은 기존 OCIO 입력 변환으로 선형 작업 공간에 읽는다. 변환 결과를 바이트로 다시 줄이지 않도록 색 이미지 저장소는 float로 지정한다. Non-Color와 별도 Alpha는 색 변환을 적용하지 않는다.

기본 축소 정책의 `.tx` 생성은 원래 알파가 곱해진 RGB를 저장했다. 이 때문에 Non-Color PNG 데이터가 알파 값만큼 줄어드는 실제 720p 결함을 확인했다. 원본 읽기·텍스처 캐시 생성·스트리밍 축소에서 OIIO의 비결합 알파를 명시한다. 스트리밍은 독립적인 64 MiB 제한 캐시를 사용한다. 이전에 잘못 만든 `.tx`를 재사용하지 않도록 자동 캐시 접미사는 `.slc-raw-v1.tx`로 구분한다. 원본 파일과 기존 사용자 캐시는 삭제하지 않는다.

`premultiplyalpha`와 `unpremultiplyalpha`는 기본 false다. 기존 엔진의 일반 이미지 API는 알파 결합을 자동으로 바꾸지 않는다. Blender 변환은 이미지 알파 모드와 최종 출력에 도달하는 Alpha 연결을 기준으로 필요한 색 처리만 요청한다. 입력 색 공간 변환 전에 RGB 결합/해제를 적용하며 별도 Alpha 채널은 유지한다. 두 속성을 이미지 캐시 키에 포함해 같은 파일을 서로 다른 색/알파 용도로 사용하는 경우도 구분한다.

Blender 5.2.1, 1280×720, 16샘플의 실제 렌더에서 CPU·Metal 각각 21조건을 검증했다. sRGB·Non-Color·Linear Rec.709·ACEScg·ACES2065-1·Linear Rec.2020 표면 여섯 조건, 사용된 Alpha·별도 Alpha·월드 다섯 조건, Premultiplied/None/Channel Packed와 알파 무시 일곱 조건, 그룹 내부 미사용/사용 및 죽은 Alpha 분기 세 조건이다. 전부 유한하고 변환 오류가 없으며 최대 평균 절대 차이는 0.002072 미만이다. 알파 무시는 1, 일반 알파는 146/255를 유지한다.

기본 스펙트럼 경로에서도 sRGB·ACEScg 표면/연결 알파/월드 각 여섯 조건을 두 장치에서 추가 검증했다. 실제 스펙트럼 플래그가 켜져 있고 최대 평균 차이는 CPU 0.002672, Metal 0.002545 미만이다. RGB와 기본 스펙트럼의 모든 비교표를 직접 검토해 암부·색·알파 분기·월드 방향을 확인했다.

원본 EXR·PNG·알파가 있는 바이트 입력·수치·로그·검토 이미지는 상위 `test-scenes/validation-2026-10-09/cycles-scene-goal-phase6/`에 보존한다. 테스트는 고정된 알파와 정적 파일 입력이다. 알파가 공간적으로 변하는 경계의 필터, 애니메이션·UDIM·생성 이미지·투영 조합과 임의 사용자 OCIO 설정의 전수 검증을 완료한 근거로 세지 않는다. 실제 설치 배포본의 확인은 다음 버전 패키지 단계에서 별도로 수행한다.
