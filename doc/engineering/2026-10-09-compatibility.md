# 2.11.13 호환성 수정과 검증

## 변경

- 범프 차분의 최소 간격을 광선 충돌 오차에서 분리했다. 월드 좌표의 부동소수점 정밀도만 보호하며, 카메라 거리나 충돌 오차 설정 때문에 미세한 표면 기울기가 과장되지 않는다. CPU와 GPU에 같은 식을 적용했다.
- Mix 텍스처에 `bumpnormal` 선택 속성을 추가했다. 기존 높이 혼합을 기본으로 유지하며, 선택 시 각 입력의 단위 법선을 혼합하고 다시 정규화한다. Cycles Bump의 Strength 처리를 위한 기능이다. SDL 직렬화, GPU 컴파일과 평가를 함께 수정했다.
- 카메라 자동 볼륨 판정은 가까운 불투명 표면을 지나 매질 경계까지 조사한다. 물체별 최초 경계의 방향과 볼륨 우선순위로 시작 매질을 찾고, 장면 변경 시 이전 매질을 초기화한다.

## 현재 소스 검증

Release 네이티브 빌드를 완료했다. `dev-tools/bump-composition-regression.py`의 높이 Add/Sub/Mix와 법선 Mix 8개 조건, `dev-tools/camera-volume-regression.py`의 Beer–Lambert 독립 기준 8개 조건이 CPU와 Apple Metal에서 통과했다. 후자는 불투명 발광면 뒤의 닫힌 흡수 볼륨, 내부/외부 카메라와 카메라 뒤쪽 볼륨을 포함한다. 정확히 겹치는 면의 교차 순서는 이 검사의 대상이 아니다.

Blender 5.2.1의 1280×720 모래 장면에서 Cycles 대비 밝기 비율은 가까운 영역 0.985, 중간 영역 0.936이었다. 이전 검증의 약 1.286/1.173보다 개선되었으나, 이 결과가 모든 절차적 범프의 동일함을 보장하지 않는다. 결과 파일은 작업 공간 `test-scenes/validation-2026-10-09`에 보존한다.

## 남은 범위

전체 호환성의 분모와 합격 기준이 정해져 있지 않으므로 99% 달성을 선언하지 않는다. 정확히 겹친 볼륨/표면, 일부 고주파 범프, 변위와 연결된 Bump Normal/Distance, 일부 노드 및 GPU 광선 연결 추정기의 차이는 추가 검증이 필요하다. 배포 후 플랫폼별 실행 검증과 실제 배포 ZIP 검증 결과는 별도 기록한다.
