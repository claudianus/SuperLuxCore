# OpenPBR lobe normals for imported Cycles materials

The published 2.11.21 runtime separates the shading frames of diffuse, base reflection/refraction, coat and fuzz. A tilted shading normal no longer determines whether an imported Principled surface is physically front-facing or back-facing. This fixes the path that discarded all light on the 2.11.20 reflection-normal baseline, without replacing the artist's normal data or the native BRDFs.

## Contracts

- `cyclesnormalsemantics` defaults to false for native OpenPBR scenes. The Cycles Principled adapter enables it.
- `reflectionnormalcorrection` defaults to false for native scenes. The adapter reads `material.cycles.use_bump_map_correction`; the Cycles default is true. Reflection and coat use the analytic guard from the installed Blender source. Raw diffuse and normal-pass data keep their own direction. Explicitly disabling the imported correction also disables imported lobe terminator attenuation; the renderer's default quality policy remains Chiang.
- Optional `coatnormal` references a normal texture. `Bump` evaluates it before base Bump changes `shadeN` and the surface partials, and stores the closure-local result in `HitPoint.coatN`. Mix children each evaluate their own cache on their own hit-point copy. The field exists in both the CPU and shared GPU HitPoint definitions.
- Diffuse, base specular/BTDF, coat and fuzz use consistent local frames in evaluation, sampling and forward/reverse densities. Opaque base reflection shades either physical face against the exterior. Refractive interfaces retain the mesh side for interior/exterior IOR selection.
- Diffuse retains EON. Only imported negative-view directions extend its evaluation to a clamped view cosine; those directions use cosine sampling and the matching density. Valid native EON inputs keep the existing BRDF and sampling model.
- Geometric reflection/transmission support is checked separately from each lobe's shading hemisphere. Samples rejected by the chosen lobe cannot be scored as another physical event by the mixture.
- Imported Cycles correction uses the per-material flag and Conty diffuse-only masking, plus the smoothed-normal support check independently of that flag. Glossy keeps its native microfacet masking and analytic normal guard. Native OpenPBR retains the selected Chiang/Conty/None policy. Terminator attenuation is applied per lobe using that lobe's normal. The outer BSDF skips its common-normal attenuation for materials owning these frames. Mixtures of two such closures preserve that convention. GPU sampling from light carries the light cosine and retains the outer geometric adjoint factor.
- Albedo does not evaluate lobe frames or read a coat cache: nested Mix albedo evaluation may occur before child Bump. Zero-energy, zero-density lobes skip evaluation, preserving nonzero reverse density. The CPU sampler also avoids evaluating imported parameters twice when the original shading view cosine is negative.

The installed source reference is Blender 5.2.1 LTS `9e2066aef7ef7e20c142ad7bd3303138a4304c93`, read from the local Blender source checkout. Relevant paths are `intern/cycles/kernel/svm/closure.h`, `kernel/closure/bsdf_util.h`, `kernel/closure/bsdf_diffuse.h`, `kernel/closure/bsdf_oren_nayar.h`, and `intern/cycles/blender/addon/properties.py`.

## Verified private source

Native Release builds complete. `dev-tools/openpbr-normal-properties-test.py` checks native defaults, both imported correction settings, optional coat texture references, texture replacement and SDL export/reparse. All three cases pass on the fixed final module. Native and imported rough-glass CPU controls also pass the existing 4% white-furnace gate at roughness 0.3, 0.5, 0.8 and 1.0 (eight controls, 32-pixel numerical regressions; these do not establish production image compatibility).

The final private module is `4631c64817a7e44d36437c7a3f25ae93040938a0fc3e6045f6ad9ed6f8edb745`. CPU and Metal have separate initialized Blender profiles and one fixed private wheel. `SuperBlendLuxCore/dev-tools/cycles-reflection-normal-test.py` runs 1280×720 Cycles 64-sample and native spectral 128-sample comparisons with noise halt disabled. Both processes completed successfully: 25 conditions each, all finite and warning/error-free. Eleven selected conditions per backend also pass a 2.5% relative mean-energy gate, with maximum observed error 1.032% (CPU) and 1.020% (Metal). Its gates cover facing, correction settings, independent coat vectors/Bump, grazing shading normals, physical backfaces, anisotropy, transmission and Mix. They do not establish complete brightness or production parity.

Earlier private iterations established visible reflection/diffuse recovery and independent coat behavior on CPU and actual Metal kernels. Their results and incomplete runs must remain separate from final-module evidence. One early Metal compile failed because lobe macros appeared after a new helper; the declaration order was fixed. A simultaneous first start in one unsynchronized dev profile also raced wheel installation; each final profile is now initialized alone before testing. These are not compatibility passes.

## Remaining acceptance work

Applying the global native Chiang term to imported glossy lobes was diagnosed as a large extra darkening (metal about 0.188 versus Cycles 0.644). The imported per-material semantics now use diffuse-only correction while preserving the native BRDF, spectral rendering and native-material quality policy. A preceding diagnostic yields corrected metal 0.64369 versus Cycles 0.64400 and diffuse 0.37244 versus 0.37248; these are diagnostics, not final-module passes. A subsequent backface test found diffuse light leakage when a raw normal pointed through the smoothed surface. The final candidate adds the Cycles support-side check even with correction disabled. Both corrected and uncorrected backface cases now pass on the fixed final hash. The separate flat-metal grazing furnace excess of about 1% and mapped transmission brightness remain open.

Principled Tangent, curve-specific guard boundaries, broader refractive/SSS combinations, mixtures with legacy closures, all bidirectional/light-tracing paths, viewport/F12, full production scenes, and local execution on other platforms remain acceptance work. Public wheel/ZIP and actual CPU/Metal installation checks are complete for the scoped 2.11.21 deployment below.

Final-module raw EXRs, PNGs, metrics, build/install logs and source fingerprints are saved in workspace `test-scenes/validation-2026-10-09/phase18/lobe-normal-candidate-2.11.21`. All four final 720p reflection/coating/backface/transmission comparison sheets have been inspected. The native Metal beauty with separate base and coat Bump is also inspected: geometry and both reflections are present; glass color/noise differs from Cycles and remains outside the completed scope. CPU and Metal each pass Add Shader (5), Normal Map (8) and Bump (5) regressions. Five selected CPU BIDIR conditions pass, including four mean-energy gates (maximum relative mean error 0.084%). Both native CPU/Metal beauties and the Cycles reference have been inspected. This is 104 native/core checks plus one reference beauty, not 104 production scenes.
